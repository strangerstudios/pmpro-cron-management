# PMPro Cron Management Security Policy

## How can I report a security bug?

You can submit a private security vulnerability report for PMPro Cron Management via [the Security tab on the GitHub repo](https://github.com/strangerstudios/pmpro-cron-management/security). For issues that also affect upstream WP Crontrol, please report them to [WP Crontrol](https://github.com/awesomemotive/wp-crontrol/security) as well.

Do not report security issues on the WordPress.org support forums or via email. Thank you.
